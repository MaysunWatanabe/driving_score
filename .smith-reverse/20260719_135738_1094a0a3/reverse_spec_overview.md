- **domain.sensorManager** (domain): センサーデータのキャリブレーション(姿勢補正)・ローパスフィルタ・回転行列演算の静的ユーティリティ。起動100msスキップの後1000ms分のサンプルを蓄積して Android SensorManager 相当の getRotationMatrix/remapCoordinateSystem/getOrientation で azimuth/pitch/roll を算出しオフセットとして固定する。以降 calibration() 呼び出しの度に加速度/磁力の rotate と accelerationIncludingGravity.lowPass をセンサーデータへ付加する。1 次 IIR ローパス(T=0.0167, F=0.2Hz)を採用。
- **domain.scoreLogic** (domain): 運転診断ロジック本体を動的に実行するランナー。Storage(environment.scoreLogicKey) から取得した JavaScript 文字列を new Function で関数化し、(currentTimestamp,lastTimestamp,geo/accel/gyro/mag/canDataList,scoreLogicJson,scoreLogicResultList,localData,log,drawGraph) の署名で呼び出す。scoreLogicInterval(既定300ms) で setInterval し、結果 JSON を Score に変換し scoreList に蓄積、calculator() で over_all/score1..4 の走行内平均を再計算する。pushSensorData でセンサ列にサンプルを追加し、environment.sensorStockTime(60秒) を超える古いサンプルを clearOldData で捨てる。testScoreLogic はブラウザ確認用の固定ダミーセンサでロジックを実行する。
