ヒヤリ録画（proposal #227 / #228 / #239）の実装前に、端末の MediaRecorder / WebM の挙動を実測する。 アプリ本体には手を触れず、アプリと同一の制約で録画して切り出しを再現する。

1. 設定

T は n より十分大きくする（T > n でないと「前 n 秒」が確保できず、起点の判定が曖昧になる）。 所要時間は T + n 秒。n=60 / T=90 なら 150 秒かかる。
